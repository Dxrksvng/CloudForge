# CloudForge

## Vision

CloudForge is an AI-native Internal Developer Platform
for deploying, operating, evaluating, securing,
and observing software and AI workloads.

## Why This Project Exists

The project has two goals:

1. Solve a realistic engineering problem.
2. Train me to understand production engineering deeply.

## Target Users

To be discovered during Stage 0.

Initial hypothesis:

Small engineering teams that need production infrastructure
but do not have a dedicated Platform/SRE team.

This is a hypothesis, not a validated fact.

## Core Problem

To be discovered and validated during Stage 0.

## Learning Goals

I want to become capable of reasoning like a strong:

- Software Engineer
- AI Engineer
- Security Engineer
- Cloud Engineer
- Platform Engineer
- Solution Architect

## Constraints

- Budget: 0 THB
- Local-first
- Open-source first
- No paid cloud required
- No paid AI API required
- Simple architecture first
- Evidence before claims

## Architecture Principle

Do not choose technology first.

Start from:

Problem
→ Requirement
→ Constraints
→ Options
→ Trade-offs
→ Decision
